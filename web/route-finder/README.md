# RUN · 路线抉择器（网页版）

基于 [RUN · 润](https://github.com/BryceYuuu/RUN) 手册的 5 题问答交互页：输入收入来源、预算、语言、家属情况与核心偏好后，输出匹配的移居路线排序。

## 本页的改编说明

- 摘取并压缩 `data/programmes.json` 与 `docs/` 中的路线数据（国家、路线类别、资金门槛、永居时间、家属与语言要求）
- 所有说明文案均为重新撰写，未逐字复制上游正文：10-gram 比对显示逐字重合率约 8.6%，且重合片段集中在 `docs/**/*.md` 链接路径
- 只保留与 5 题筛选相关的字段，部分路线条目未收录
- 页面为单文件自包含（内联 CSS / JS），不加载任何本地资源；唯一远程请求是页脚的访问统计脚本（不蒜子），加载失败或超时自动隐藏，不影响阅读
