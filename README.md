# RUN · 路线抉择器

一个自包含的 5 题问答网页：输入收入来源、预算、语言、家属情况与核心偏好，输出匹配的移居路线排序。

单文件 `index.html`（内联 CSS/JS），浏览器直接打开即可，不上传任何答题内容。唯一的远程请求是页脚的访问统计脚本（不蒜子）：加载失败或超时会自动隐藏统计行，不影响页面阅读与使用。

## 部署

本仓库的 `gh-pages` 分支只存放静态页面，通过 GitHub Pages 发布于：

```
https://adeople.github.io/RUN/
```

同源内容另有一份托管在豆包网页（doubao.link），两处内容一致，改页面时两边都要更新。豆包域名长度超过 22 字符，不满足不蒜子的接入限制，那份页面的统计行会保持隐藏。
